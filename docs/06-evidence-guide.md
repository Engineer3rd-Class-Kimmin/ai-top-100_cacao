# 기록의 출처와 공개 범위

## 검토한 두 채팅

| 구분 | 실제 채팅 제목 | 검토 범위 |
|---|---|---|
| A | 범용 AI Agent Harness 구축 | 도구가 반환한 전체 18페이지, 175턴 |
| B | 구현·검증: Qwen3.8 27B 액션 API | 도구가 반환한 전체 4페이지 중 과거 완료 33턴 |

도구는 현재 작성 요청 1턴을 포함해 총 209턴을 반환했다. 과거 기록으로 검토한 것은 그 요청을 제외한 208턴이다. 턴 하나에 사용자 보완 메시지·여러 도구 실행·여러 답변이 있을 수 있어 메시지 수나 인터뷰 질문 수와 같지 않다. 이 포트폴리오 작업의 신규 대화는 당일 회고에서 제외했다. 이전 준비 기간과 종료 후 회고도 읽었지만, 본문 시간축은 2026-10-31 10:00~15:00 KST에 맞췄다.

도구가 제공한 채팅 텍스트와 상태·도구 실행 항목을 검토했다. 채팅에 첨부됐던 모든 화면을 이번에 다시 재생·열람했다는 뜻은 아니다. 공개용 기록에는 원문 채팅과 첨부를 포함하지 않았다.

파일별 해시는 [source-manifest.json](../evidence/source-manifest.json), 허용 필드만 추출한 수치는 [summary.json](../evidence/summary.json)에 기록했다. 해시는 검토한 파일 버전을 식별할 뿐 내용의 정확성을 독립적으로 증명하지는 않는다. 원본이 비공개이므로 제3자가 이 저장소만으로 모든 당시 API 접수 사실을 재검증할 수는 없다.

채팅의 당시 결과 보고와 로컬 산출물이 다를 때는 측정 시점·버전을 나눠 설명했다. 예를 들어 252개는 정리 전, 245개는 실습 전용 테스트를 정리한 뒤의 수치다. 마지막 READY는 연결 상태 기록이고 최종 고객 업무 성공과 다르다.

## 수치의 의미

- **45.8%:** 관계자별 발굴률 10개 표시의 산술 평균. 전체 참가자 평균이 아니다.
- **174:** 확인된 공개 검색 레코드 수. 공식 발굴 지식 수가 아니다.
- **15개 실습 성공:** 각 사례의 마지막 선택 시도 집계. 최종 일반 상담 인증 E2E 성공률이 아니다.
- **p95:** 각 보고서가 기록한 서버 수신→콜백 완료 표본 지연. 공식 심사 점수가 아니다.
- **245개:** 당시 운영 프로젝트의 최종 로컬 회귀 검사. 이 공개 저장소의 테스트 개수와 다르다.

## 운영 소스에서 선별한 코드

`examples/request_adapter.py`는 검토 시점의 운영 소스에서 그대로 복사했다. 표준 라이브러리로 실행할 수 있는 정규화·진단 기능을 공개 테스트 대상으로 골랐다. `handle_skill_request`는 전체 서비스와 콜백 모듈을 요구하는 인프로세스 진입점으로, 이 축약 저장소의 실행 대상이 아니다. 전체 봇이나 실제 스킬 HTTP 서버를 제공하는 배포 패키지가 아니다.

`tests/test_request_contract.py`는 이 파일을 독립적으로 확인하기 위해 포트폴리오 작성 시 추가했다. 합성 입력만 사용하고, 실제 고객 메시지·ID·토큰·주문 데이터는 사용하지 않는다.

## 공개하지 않은 것

대회 원본 문서와 인터뷰 전문, 고객·회원·주문·결제·배송 데이터, 음성·사진 원본, 실제 접수번호, 인증 정보, 로그 원문, `.env`, 모델 파일과 운영 DB는 포함하지 않았다. 대회 화면·문제 원문을 그대로 복제하지 않고 기술적 접근과 결과를 새 문장으로 작성했다. 공식 평가 결과·순위는 미확인이다.

이 저장소를 만들면서 원래 프로젝트를 수정하거나 액션 API를 재실행하지 않았다. 공개 저장소의 검사 결과는 당시 심사 환경의 재현이 아니라 공개한 코드와 문서의 확인이다.
